Use the main calculator at the top of the page, above the What Is a Number Sum Calculator heading. The example cards below are demonstrations and are not part of this scenario.
1. Enter 1, 2, and 4 on separate lines in the topmost Input text field.
2. Select the first Number Delimiter radio button, in the main Tool options section above the examples. Keep its default line-break separator.
3. Check that the topmost Total output beside Input text displays 7.
Stop after this check.
